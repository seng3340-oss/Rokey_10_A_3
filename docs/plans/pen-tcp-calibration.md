# 실제 펜촉 TCP 교정 연결

목표: 실제 모드에서도 측정된 펜촉 TCP를 등록·적용한 뒤 케이크 중심 영점을 받는다. 가상 TCP 길이를 실물에 복사하지 않는다.

1. 순수 계산 모듈: 같은 기준점을 접촉한 네 플랜지 자세에서 `R_i t + p_i = c` 최소제곱으로 플랜지→펜촉 오프셋을 구한다. 랭크·조건수·잔차를 검사한다.
2. 첫 측정 자세에서 물리적 펜을 수직 아래로 두고, 그 방향을 TCP +Z로 정의한다. 위치 교정과 펜축 방향 설정을 함께 다룬다.
3. 실물 교정 절차: 수동 교시 기간에 수동 모드를 사용하고 입력마다 플랜지 자세만 읽는다. 위치 이동·그리퍼 명령은 보내지 않는다. 측정 종료·취소 시 모드를 복원하고, 계산값을 표시한 뒤 APPLY를 입력한 경우에만 새 이름으로 등록·선택한다.
4. TCP 등록에 필요한 수동 모드 전환은 기존 모드를 기록한 뒤 설정 작업에만 사용하고 finally에서 복원한다. 기존 TCP 항목은 덮어쓰지 않는다.
5. 적용 직후 활성 이름과 현재 TCP 위치·자세를 플랜지+교정값 계산과 비교한다. 실패하면 웹과 주문 처리를 시작하지 않는다.
6. 성공한 실측값은 `config/local/pen_tcp.json`에 저장하고 Git에서는 제외한다. 재사용은 펜 고정 상태가 같은지 운영자가 USE로 확인한다.
7. 실물 TCP가 플랜지 중심이면 교정 절차를 먼저 진행한다. `--calibrate-pen-tcp`로 명시적인 재교정도 지원한다. 교정 후에 기존 케이크 상면 중심 YES를 받는다.
8. 장비 없는 합성 데이터 검사·잘못된 자세 거부·가짜 ROS 서비스로 등록/모드복원/실패 중단·기존 실행기 회귀 검사를 수행한다. 실제 로봇을 자동 실행해 검증하지 않는다.

실제 펜의 길이와 장착 방향은 기존 한 자세에서 유추할 수 없다. 네 자세의 접촉 측정은 운영자가 수행해야 한다.
