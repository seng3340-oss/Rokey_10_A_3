# 원뿔대 케이크 표면 드로잉

## 형상과 입력

공통 치수는 `config/test_cake.json`의 윗지름113.5mm·밑지름120mm·높이79mm다.
프론트3D 미리보기는 이 형상을 표시하고, 옆면 필기는 직사각형 영역에서 받는다.
프론트는 원본1024×768 캔버스의 픽셀과 획 순서를 보내며 로봇 좌표로 변환하지 않는다.
백엔드는 주문 접수 당시 치수 사본을 함께 보존한다. 과거 주문은 자동 변환하지 않는다.

## 좌표와 이동

- `drawing_geometry.py`: 높이에 따른 실제 반지름과 표면 법선을 계산한다.
- `frustum_path.py`: 높이가 바뀌어도 같은 가로 픽셀의 각도를 유지하도록 실행용 호 좌표를 변환한다.
- `surface_path.py`: 수평 구간은 최대90도씩 원호로, 수직 구간은 경사면을 따르는 직선으로 구성한다.
- `drawing_path_node.py`: 대각선·곡선은 표면 목표점을 만들고 최대100점씩 스플라인으로 묶는다.
- `drawing_motion.py`, `robot_executor_node.py`, `doosan_robot.py`: 명령 종류와 경유점·표본을 보존해 MoveLine·MoveCircle·MoveSpline을 호출한다.

옆면의 실제 반지름은 아래60mm, 위56.75mm이며 중간 높이에서는58.375mm다.
실행용 평균 반지름은 각도 환산 기준일 뿐 실제 케이크를 원통으로 취급하는 값이 아니다.
표면 위 두 점을 단순 직선으로 연결하면 안쪽을 지나갈 수 있어 수평 구간의 원호 명령을 유지한다.

## 영점과 펜 자세

`start_real.sh`에서 YES를 입력하면 현재 활성 TCP의 BASE 위치를 케이크 상면 중심으로 기록한다.
높이와 판 두께를 다시 더하지 않는다. PR #16의 영점 펜 자세 보존도 유지한다.
`cake_pose.orientation`은 기록한 펜 자세이며 케이크 평면 회전 `cake_yaw`와 구분한다.
상면은 기록한 자세를 쓰고 옆면은 수직 기준30도 기울기를 사용한다.
원뿔대의 경사 법선을 반영할 때도 이30도 기준이 바뀌지 않도록 보정한다.

첫 옆면 접근은 기록한 자세로 상승하고 케이크 바깥으로 이동한 뒤 옆면 자세로 전환한다.
획 사이에는 법선 방향10mm 밖으로 물러나 표면 바깥 경로를 따라 이동한다.
직선·원호·스플라인 서비스 응답뿐 아니라 목표 TCP 도달도 검사한다.

## 장비 없이 실행하는 검사

ROS 인터페이스를 새로 빌드한 뒤 실행한다. 드라이버나 로봇을 실행하는 명령은 아니다.

```bash
source /opt/ros/jazzy/setup.bash
source ws_cobot1/install/setup.bash
python3 -m pytest ws_cobot1/src/cake_decorator/test ws_cobot1/src/cake_decorator_interfaces/test
```

원뿔대 통합 회귀 검사는 `test_frustum_integration.py`와 `test_frustum_command_contract.py`에 있다.
수평 원호, 경사면 수직선, 스플라인 목표점, 획 사이 여유, 영점 자세, ROS 직렬화와 두산 요청 생성을 확인한다.
회귀 테스트의 서비스 기록기는 테스트 안에서만 사용하며 실제 실행 코드는 이를 사용하지 않는다.

## 검증 한계

스플라인 목표점이 표면에 일치하더라도 실제 제어기의 전체 보간 곡선이 같다고 보장하지 않는다.
로봇·그리퍼·펜 몸체 충돌, 관절 도달성, 접촉 압력과 실제 레터링 품질은 장비에서 확인해야 한다.
기존100×80mm 원통 전용 가상 잉크와 일회성 파형 시험·생성 결과는 현재 실행 구성에서 제거했다.
가상 기동용 펜 모델과 TCP 초기화는 유지하지만, 가상 기동만으로 실제 원뿔대 드로잉이 검증되지는 않는다.
