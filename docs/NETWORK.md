# 태블릿과 로봇 연결

노트북의 Ethernet과 Wi-Fi는 별도 인터페이스다. 로봇에 LAN 포트를 사용하면서
Wi-Fi로 태블릿 및 인터넷에 연결할 수 있다. 외부 인터넷 없이도 같은 로컬망에서 웹 접속이 가능하다.

예시 주소이며 실제 설정을 적용하거나 변경한 상태는 아니다.

- 로봇: Ethernet, 192.168.1.100/24
- 노트북 유선: 192.168.1.10/24, 기본 게이트웨이·DNS 미설정
- Wi-Fi 공유기: 192.168.50.1/24
- 노트북 Wi-Fi: 192.168.50.20/24
- 태블릿 Wi-Fi: 192.168.50.21/24
- 태블릿 접속 예시: http://192.168.50.20:8000 (서버 구현 후)

로봇망과 Wi-Fi망은 겹치지 않는 대역으로 구성한다.
로봇 유선 프로필은 ipv4.never-default를 사용해 기본 인터넷 경로가 되지 않게 하고,
Wi-Fi를 인터넷 기본 경로로 사용한다. 로봇을 인터넷에 중계할 필요는 없다.
서버는 외부 인터페이스에서 요청을 받도록 바인딩하고 필요한 웹 포트의 방화벽 접근을 허용해야 한다.
공용 Wi-Fi의 AP 격리나 조직 정책으로 기기 간 접속이 차단되면 개인 공유기를 사용하는 방안을 검토한다.
같은 SSID에 접속했다고 반드시 기기 간 통신이 되는 것은 아니다.

공식 설정 설명: https://www.networkmanager.dev/docs/api/latest/settings-ipv4.html
