# 수직 접촉점으로 펜촉 TCP 추정하기

실물 테스트 전용 옵션입니다. 기본 실행은 기존 활성 TCP를 그대로 사용합니다.
이 옵션은 케이크 상면의 실제 BASE 높이를 알고, 펜을 수직으로 세웠을 때만 사용합니다.
현재 테스트 입력은 안착면139 + 케이크판2 + 케이크79 = 220mm입니다.
실물에서 이 높이가 다르면 입력값을 바꿔야 합니다.

```bash
cd ~/ws_cobot_pjt
bash scripts/start_real.sh --calibrate-pen-tcp --cake-top-z-mm 220
```

실행기는 완성된 로봇 설치본을 자동으로 선택하고 경로를 표시합니다.
이전 미완료 주문이 있으면 작업이 실제 중단됐는지 확인한 뒤 RESET을 입력합니다.
이 확인은 기존 주문의 잠금만 해제하며, 주문 삭제나 재실행은 하지 않습니다.

펜을 수직 아래로 세워 실제 펜촉을 상면 중앙에 가볍게 닿게 놓습니다.
펜과 로봇을 움직이지 않는 상태에서 YES를 입력합니다.
현재 TCP의 XY가 실제 펜촉 XY와 같다고 가정하며, 이를 한 점 측정으로 검증할 수는 없습니다.
현재 도구 +Z축이 수직 아래에서 2도 넘게 벗어나면 등록하지 않습니다.

프로그램은 현재 플랜지 자세를 읽고, 펜촉의 목표 위치를 `(현재 TCP X, 현재 TCP Y, 220)`으로 둡니다.
이 BASE 좌표를 플랜지 좌표계로 변환해 `CakePen_...`라는 별도 TCP로 등록합니다.
기존 TCP를 덮어쓰지 않습니다. 설정 중 수동 모드로 전환하고 원래 모드로 돌아옵니다.
실제 관절을 움직이는 명령이나 그리퍼 명령은 보내지 않습니다.

적용 후 표시되는 TCP가 예상 좌표와 일치하는지, 관절이 움직이지 않았는지 검사합니다.
이는 설정의 일관성을 확인하는 것이며 실제 펜촉 접촉 오차를 측정하는 검사는 아닙니다.
먼저 펜던트의 수동 점고정으로 실제 펜 끝이 유지되는지 확인한 뒤 웹 제작 요청을 사용합니다.
케이크에 닿은 상태에서 프로그램이 자동으로 기울이는 시험은 하지 않습니다.

기록은 `log/system/실행시각-real-PID/contact_tcp.json`에 남습니다.
새 테스트 TCP는 종료 후에도 로봇에 적용된 상태로 남습니다.
기존 설정으로 돌리려면 펜던트에서 터미널에 표시된 `이전 TCP 복원 이름`을 선택합니다.
이전 TCP 이름이 비어 있었다면 원래 수치 설정을 `CakePrev_...` 이름으로 보관합니다.
실패하면 기존 설정으로 복원을 시도하며, 통신 문제로 확인할 수 없으면 터미널에 알립니다.

한 점 추정으로 정밀 TCP 교정을 대신할 수는 없습니다.
상면 높이·펜의 수직 정렬·XY 가정의 오차가 실제 펜촉 고정 오차로 남습니다.

## 옆면 그리기 속도

현재 기울기는 수직 기준15도다. 옆면 접촉 후 기준 선속도60mm/s,
선가속도300mm/s², 자세 각속도60도/s·각가속도120도/s²를 사용한다.
접촉 진입은 기존15mm/s(가동속도100% 기준)를 유지한다.
실제 속도는 가동속도 비율과 관절·자세 제한에 따라 낮아질 수 있다.

실행기를 다시 켜고 펜촉·영점을 준비한 다음, 웹에서 직접 옆면 그림을 그려 제출한다.
