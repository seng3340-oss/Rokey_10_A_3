# 펜촉 TCP 설정과 옆면 드로잉

실물 실행은 config/real_robot.json 설정에 따라 YES 후 펜촉 TCP를 계산·적용합니다.
이 계산은 케이크 상면의 실제 BASE 높이를 알고, 펜을 수직으로 세웠을 때만 사용합니다.
현재 상면 높이는 안착면139 + 케이크판2 + 케이크79 = 220mm입니다.
실물에서 이 높이가 다르면 입력값을 바꿔야 합니다.

```bash
cd ~/ws_cobot_pjt
bash scripts/start_real.sh
```

실행기는 완성된 로봇 설치본을 자동으로 선택하고 경로를 표시합니다.
이전 미완료 주문이 있으면 작업이 실제 중단됐는지 확인한 뒤 RESET을 입력합니다.
이 확인은 기존 주문의 잠금만 해제하며, 주문 삭제나 재실행은 하지 않습니다.

펜을 수직 아래로 세워 실제 펜촉을 상면 중앙에 가볍게 닿게 놓습니다.
펜과 로봇을 움직이지 않는 상태에서 YES를 입력합니다.
현재 TCP의 XY가 실제 펜촉 XY와 같다고 가정하며, 이를 한 점 측정으로 검증할 수는 없습니다.
현재 도구 +Z축이 수직 아래에서 2도 넘게 벗어나면 등록하지 않습니다.

프로그램은 현재 플랜지 자세를 읽고, 펜촉의 목표 위치를 `(현재 TCP X, 현재 TCP Y, 220)`으로 둡니다.
이 BASE 좌표를 플랜지 좌표계로 변환해 `CakePen_...`라는 별도 TCP로 등록합니다.
기존 TCP를 덮어쓰지 않습니다. 설정 중 수동 모드로 전환하고 원래 모드로 돌아옵니다.
실제 관절을 움직이는 명령이나 그리퍼 명령은 보내지 않습니다.

적용 후 표시되는 TCP가 예상 좌표와 일치하는지, 관절이 움직이지 않았는지 검사합니다.
이는 설정의 일관성을 확인하는 것이며 실제 펜촉 접촉 오차를 측정하는 검사는 아닙니다.
먼저 펜던트의 수동 점고정으로 실제 펜 끝이 유지되는지 확인한 뒤 웹 제작 요청을 사용합니다.
케이크에 닿은 상태에서 프로그램이 자동으로 기울이는 시험은 하지 않습니다.

기록은 `log/system/실행시각-real-PID/contact_tcp.json`에 남습니다.
새 펜촉 TCP는 종료 후에도 로봇에 적용된 상태로 남습니다.
기존 설정으로 돌리려면 펜던트에서 터미널에 표시된 `이전 TCP 복원 이름`을 선택합니다.
이전 TCP 이름이 비어 있었다면 원래 수치 설정을 `CakePrev_...` 이름으로 보관합니다.
실패하면 기존 설정으로 복원을 시도하며, 통신 문제로 확인할 수 없으면 터미널에 알립니다.

한 점 추정으로 정밀 TCP 교정을 대신할 수는 없습니다.
상면 높이·펜의 수직 정렬·XY 가정의 오차가 실제 펜촉 고정 오차로 남습니다.

## 옆면 그리기 속도

현재 기울기는 수직 기준20도다. 옆면 접촉 후 기준 선속도60mm/s,
선가속도300mm/s², 자세 각속도60도/s·각가속도120도/s²를 사용한다.
접촉 진입은 기존15mm/s(가동속도100% 기준)를 유지한다.
실제 속도는 가동속도 비율과 관절·자세 제한에 따라 낮아질 수 있다.

실행기를 다시 켜고 펜촉·영점을 준비한 다음, 웹에서 직접 옆면 그림을 그려 제출한다.

## 옆면 도달 가능 자세 선택

웹에서 옆면을 제출하면 이동 전에 제어기의 역기구학·순기구학으로 자세 후보를 검사한다.
펜촉 위치와20도 기울기를 유지하면서 펜축 둘레 회전만15도 간격으로 바꾼다.
현재 팔의 관절 해를 유지하고, 시작점에 가능한 후보부터 명령 목표·원호 경유점·스플라인 시작과 끝을 확인하고 내부 표본은 간격을 두고 검사한다.
선택 결과와 예상 J6 범위는 실행 터미널과 기존 로그에 저장한다.
가능한 후보가 없거나90초가 지나면 이동하지 않고 주문을 실패 처리한다.
표본의 도달 가능성은 실제 제어기의 보간 경로 전체나 충돌·접촉 품질을 보장하지 않는다.
실행 명령과 웹 제출 절차는 동일하다.

획 사이 공중 이동은 상면 위로 올라가 최대 반지름 바깥에서 돌아간다.
5도 미만의 짧은 이동은 원 밖의 두 접선을 사용해 작은 원호를 만들지 않는다.
높이가 다른 획 사이를 미세 원호·수직 이동 수백 개로 분할하던 처리는 사용하지 않는다.

## 굵은 펜촉의 옆면 접촉 보정

실제 케이크는 윗지름113.5mm·밑지름120mm로 유지한다.
`workspace_config.yaml`의 `side_diameter_allowance_mm: 2.0`은 옆면 펜촉 목표를
반지름 방향으로1mm 바깥에 둔다는 뜻이다. 0으로 바꾸면 기존 표면 경로다.
케이크 모델·웹 치수·윗면 경로·목표 높이와 그림의 원주 각도는 유지한다.
실행기를 재시작해야 적용된다.

사전 검사의 스플라인 내부점은20개 간격·누적 이동10mm·자세 차이10도 중 먼저
해당하는 지점에서 확인한다. 20도 이상 꺾이는 지점도 검사한다.
최초 기울이기와 명령 경계는 보존하며, 실제 이동 뒤 목표 도달 확인도 유지한다.
이는 사전 검사 시간 단축을 위한 표본 검사이며 생략한 구간의 도달 가능성을 보장하지 않는다.
