# 펜촉 TCP 설정과 옆면 드로잉

## 로봇 없이 45도 옆면 그리기 확인

```bash
cd ~/ws_cobot_pjt
bash scripts/start_virtual_side_web_test.sh
```

이 명령 하나로 에뮬레이터, RViz, 웹과 백엔드를 켭니다. `sodreal`은 필요하지 않습니다.
실물과 분리한 ROS 도메인187, 웹8081, 백엔드5001을 사용합니다.
주문은 이번 가상 실행 폴더의 별도 DB에 저장하며 실제 로봇 주소는 허용하지 않습니다.

45도 펜을 이미 파지한 가상 자세에서 케이크 중앙으로 이동합니다.
터미널에서 `YES`를 입력하면 펜을 올리고 웹을 준비합니다.
`http://localhost:8081`에서 **옆면**을 선택해 그림을 제출하면 RViz에서 움직임을 볼 수 있습니다.
실물과 같은 펜촉 방향·회전·이동 경로를 실행하고, 그리기 뒤 기본 TCP로 초기화합니다.
이 가상 모드는 펜 반납과 그리퍼 조작을 생략합니다. 실물의 반납 동작은 유지합니다.
한 번 검증한 뒤 다른 그림을 시험하려면 Ctrl+C로 종료하고 같은 명령을 다시 실행합니다.

표시된 펜촉은 교정값 `(1.095, -46.474, 271.695)`mm에 맞춥니다.
펜 몸통의 길이·굵기는 시각화용이며, 가상 검증은 경로·관절·TCP 전환 확인용입니다.
실제 펜 마찰, 케이크 변형과 필압은 에뮬레이터에서 검증하지 않습니다.

## 45도 파지 펜의 옆면 웹 검증

거치대 이탈·케이크 상공 접근은 100mm/s, 중앙 확인 하강은 30mm/s,
YES 뒤 수직 이탈은 60mm/s로 설정합니다. 획 사이 공중 이동 기준은 100mm/s이며
접촉해서 그리는 기준 속도는 기존 30mm/s를 유지합니다.
반납 직선 이동은 60mm/s, 반납 관절 이동은 30도/s입니다.

`sodreal`로 연결하고 45도로 파지한 펜을 준비한 뒤 실행합니다.

```bash
cd ~/ws_cobot_pjt
bash scripts/start_real_side_web_test.sh
```

실행기가 `Pen_Side_45` TCP를 적용하고, 거치대 위로 이탈한 뒤
설정된 케이크 상면 중심으로 이동해 펜촉을 내립니다. RG2는 수직이고
펜은 45도로 물린 상태를 유지합니다. 이때 그리기를 시작하지 않고 기다립니다.
중앙과 접촉 상태를 확인하고, 필요하면 펜던트로 위치를 보정한 뒤 `YES`를 입력합니다.
확인한 펜촉 XYZ를 이번 작업의 상면 중심으로 저장하고, XY와 자세를 유지하며
BASE Z 방향으로 50mm 올립니다. 그다음 웹에서 옆면 그림을 제출합니다.

확인 위치는 `config/real_robot.json`의 `side_cake_center_xy_mm`와
`cake_top_z_mm`로 지정합니다. 초기값은 이전에 케이크에서 확인한
BASE `(399.274, -54.559, 220)`mm입니다. 거치대 위 현재 위치나 최신 실행 로그를
케이크 중심으로 자동 선택하지 않습니다. 설정은 실행기를 다시 켜면 반영됩니다.

접촉 여부는 운영자가 확인합니다. 접근이나 이탈에 실패하면 실행 준비를 중단합니다.
확인한 중심과 이탈 후 시작 자세는 이번 실행 폴더의 `reference.json`에 남습니다.

이 검증에서만 `Pen_Side_45` TCP를 사용합니다. 그리기와 펜 반납이 끝나면
`set_tcp("")`에 해당하는 서비스로 선택을 해제해 기본값
`0,0,0,0,0,0`으로 돌아갑니다. 등록된 `Pen_Side_45` 항목은 삭제하지 않습니다.
작업 실패·취소와 실행기 종료 때도 정지를 확인한 뒤 초기화를 시도합니다.
중앙 확인 중 종료한 경우도 같습니다. 초기화 뒤에는 TCP와 플랜지 위치·자세가
같은지 검사합니다. 통신 단절이나 강제 종료(SIGKILL) 때는 복원을 보장할 수 없습니다.
실행기 종료 시 결과는 이번 실행 폴더의 `tcp_restore.log`에 기록됩니다.

빈 TCP 이름으로 선택을 해제하는 동작과 수동 모드 조건은
[두산 DRFL set_tcp 설명](https://doosanrobotics.github.io/doosan-robotics-api-manual/GL013305/mode/common/tcp/set_tcp.html)을 따릅니다.

## 수직 펜의 상면 영점

실물 실행은 config/real_robot.json 설정에 따라 YES 후 펜촉 TCP를 계산·적용합니다.
이 계산은 케이크 상면의 실제 BASE 높이를 알고, 펜을 수직으로 세웠을 때만 사용합니다.
현재 상면 높이는 안착면139 + 케이크판2 + 케이크79 = 220mm입니다.
실물에서 이 높이가 다르면 입력값을 바꿔야 합니다.

```bash
cd ~/ws_cobot_pjt
bash scripts/start_real.sh
```

실행기는 완성된 로봇 설치본을 자동으로 선택하고 경로를 표시합니다.
이전 미완료 주문이 있으면 작업이 실제 중단됐는지 확인한 뒤 RESET을 입력합니다.
이 확인은 기존 주문의 잠금만 해제하며, 주문 삭제나 재실행은 하지 않습니다.

펜을 수직 아래로 세워 실제 펜촉을 상면 중앙에 가볍게 닿게 놓습니다.
펜과 로봇을 움직이지 않는 상태에서 YES를 입력합니다.
현재 TCP의 XY가 실제 펜촉 XY와 같다고 가정하며, 이를 한 점 측정으로 검증할 수는 없습니다.
현재 도구 +Z축이 수직 아래에서 2도 넘게 벗어나면 등록하지 않습니다.

프로그램은 현재 플랜지 자세를 읽고, 펜촉의 목표 위치를 `(현재 TCP X, 현재 TCP Y, 220)`으로 둡니다.
이 BASE 좌표를 플랜지 좌표계로 변환해 `CakePen_...`라는 별도 TCP로 등록합니다.
기존 TCP를 덮어쓰지 않습니다. 설정 중 수동 모드로 전환하고 원래 모드로 돌아옵니다.
실제 관절을 움직이는 명령이나 그리퍼 명령은 보내지 않습니다.

적용 후 표시되는 TCP가 예상 좌표와 일치하는지, 관절이 움직이지 않았는지 검사합니다.
이는 설정의 일관성을 확인하는 것이며 실제 펜촉 접촉 오차를 측정하는 검사는 아닙니다.
먼저 펜던트의 수동 점고정으로 실제 펜 끝이 유지되는지 확인한 뒤 웹 제작 요청을 사용합니다.
케이크에 닿은 상태에서 프로그램이 자동으로 기울이는 시험은 하지 않습니다.

기록은 `log/system/실행시각-real-PID/contact_tcp.json`에 남습니다.
새 펜촉 TCP는 종료 후에도 로봇에 적용된 상태로 남습니다.
기존 설정으로 돌리려면 펜던트에서 터미널에 표시된 `이전 TCP 복원 이름`을 선택합니다.
이전 TCP 이름이 비어 있었다면 원래 수치 설정을 `CakePrev_...` 이름으로 보관합니다.
실패하면 기존 설정으로 복원을 시도하며, 통신 문제로 확인할 수 없으면 터미널에 알립니다.

한 점 추정으로 정밀 TCP 교정을 대신할 수는 없습니다.
상면 높이·펜의 수직 정렬·XY 가정의 오차가 실제 펜촉 고정 오차로 남습니다.

## 옆면 그리기 속도

현재 기울기는 수직 기준20도다. 옆면 접촉 후 기준 선속도60mm/s,
선가속도300mm/s², 자세 각속도60도/s·각가속도120도/s²를 사용한다.
접촉 진입은 기존15mm/s(가동속도100% 기준)를 유지한다.
실제 속도는 가동속도 비율과 관절·자세 제한에 따라 낮아질 수 있다.

실행기를 다시 켜고 펜촉·영점을 준비한 다음, 웹에서 직접 옆면 그림을 그려 제출한다.

## 옆면 도달 가능 자세 선택

웹에서 옆면을 제출하면 이동 전에 제어기의 역기구학·순기구학으로 자세 후보를 검사한다.
펜촉 위치와20도 기울기를 유지하면서 펜축 둘레 회전만15도 간격으로 바꾼다.
현재 팔의 관절 해를 유지하고, 시작점에 가능한 후보부터 명령 목표·원호 경유점·스플라인 시작과 끝을 확인하고 내부 표본은 간격을 두고 검사한다.
선택 결과와 예상 J6 범위는 실행 터미널과 기존 로그에 저장한다.
가능한 후보가 없거나90초가 지나면 이동하지 않고 주문을 실패 처리한다.
표본의 도달 가능성은 실제 제어기의 보간 경로 전체나 충돌·접촉 품질을 보장하지 않는다.
실행 명령과 웹 제출 절차는 동일하다.

획 사이 공중 이동은 상면 위로 올라가 최대 반지름 바깥에서 돌아간다.
5도 미만의 짧은 이동은 원 밖의 두 접선을 사용해 작은 원호를 만들지 않는다.
높이가 다른 획 사이를 미세 원호·수직 이동 수백 개로 분할하던 처리는 사용하지 않는다.

## 굵은 펜촉의 옆면 접촉 보정

실제 케이크는 윗지름113.5mm·밑지름120mm로 유지한다.
`workspace_config.yaml`의 `side_diameter_allowance_mm: 3.5`은 옆면 펜촉 목표를
반지름 방향으로1.75mm 바깥에 둔다는 뜻이다. 0으로 바꾸면 기존 표면 경로다.
케이크 모델·웹 치수·윗면 경로·목표 높이와 그림의 원주 각도는 유지한다.
실행기를 재시작해야 적용된다.

사전 검사의 스플라인 내부점은20개 간격·누적 이동10mm·자세 차이10도 중 먼저
해당하는 지점에서 확인한다. 20도 이상 꺾이는 지점도 검사한다.
최초 기울이기와 명령 경계는 보존하며, 실제 이동 뒤 목표 도달 확인도 유지한다.
이는 사전 검사 시간 단축을 위한 표본 검사이며 생략한 구간의 도달 가능성을 보장하지 않는다.

### 옆면 Y 양쪽 접촉 보정

`bash scripts/start_real_side_web_test.sh --side-y-inset-mm 1`

기본값은 양쪽 각각 1mm(전체 Y 폭 2mm 감소)다. `0`이면 보정을 끈다.
값은 0~5mm로 입력하며, 실행기를 다시 시작해야 적용된다.
BASE Y 기준으로 중심 쪽으로 부드럽게 줄이며 X/Z와 중심, 기존 지름 유격은 유지한다.
순응·힘제어는 추가하지 않고 위치 경로만 보정한다.

### 검증된 실물 시험의 자동 진행

`start_real_pen_pick_45.sh`는 YES 입력 없이 파지·인출·수직 복귀까지 진행한다.
`start_real_side_web_test.sh`도 중심 접촉 후 YES 대기 없이 기록·상승하고 웹을 준비한다.
두 명령은 실행 직후 로봇 이동이 시작되며, 웹 주문의 그리기 실행 방식은 유지한다.

### 옆면 획 내부 정지 감소

45도 펜 웹 검증은 수평·수직·대각선을 모두 한 획 단위 movesx로 묶는다.
기존 수평 원호의 최대 90도 단위 명령 분할을 제거했다.
원주 표본은 1도에서 최대 4도(현 처짐 기준 0.05mm), 높이 간격은 0.5mm에서 1mm로 변경했다.
현재 크기의 수평 한 바퀴는 원호 4개 대신 스플라인 1개로 전송된다.
다만 복잡한 획은 제어기 100점 제한으로 나뉠 수 있다.
그리기 속도·접촉 진입·획 사이 펜 이탈·도달 검사는 유지한다. 실물 정지시간 단축량은 별도 측정이 필요하다.
