# 윗면·옆면 전체 공정 통합 계획

- [x] 현재 실물 옆면 검증 코드를 커밋하고 통합 브랜치 분기.
- [x] 원격 main 전체 공정과 윗면 높이 출처 조사.
- [x] 팀원 plate_prepare → DrawOnCake → plate_finish 통신 유지. TM이 TOP 후 SIDE 순서로 실행.
- [x] TOP 기본 TCP 티칭 Z와 SIDE 펜촉 TCP Z를 분리해 전달. 중앙 접촉 검사 제외.
- [x] RE가 SIDE 작업에만 45도 파지·펜촉 TCP 전환·연속 그리기·J6 되감기·반납·기본 TCP 복원.
- [x] start_real.sh 한 번으로 기동. 모의 로봇 테스트·기존 회귀 테스트·빌드 검증.
- [ ] 실제 장비 전체 사이클 검증은 사용자가 진행. 검증용 파일 삭제는 사용자의 최종 승인 후.

윗면 Z=510.39mm는 기본 TCP(플랜지) 티칭 기준이며 실제 상면 Z=222mm와 직접 비교하지 않는다.
윗면 누름 깊이는 펜 길이·파지 깊이를 포함해 실측해야 하므로 이번 통합에서 임의로 변경하지 않는다.
