
### 웹 주문 본문 확장

기존 한 면 필드(canvas_width, canvas_height, drawing_surface, strokes)를 유지한다.
두 면이면 TOP을 기본 본문으로 보내고 `additional_paths: [SIDE의 동일한 필드]`를 추가한다.
추가 면은 최대 하나이며 중첩하지 않는다. SQLite에는 같은 주문의 drawing_json에 함께 저장한다.
백엔드와 브릿지 모두 두 면 합계 100획/20,000점 제한과 각 면의 픽셀 범위를 검사한다.

그리기 Action 취소는 자식 실행기에 전달하고 정리 결과를 기다린다. 결과가 불명확하면 새 주문을 막는다.
운반의 Trigger 서비스는 취소를 지원하지 않으므로 PREPARING/FINISHING 단계에서는 ROS 주문 취소를 거절한다.
웹/ROS 취소는 물리적 비상정지 기능이 아니다.

## TCP 복원 로그 구분

그리기 실패 뒤 `motion/move_stop` 응답 실패가 TCP 변경 전에 발생해도 이전에는 전체가 TCP 복원 실패로 표시됐다.
이제 정지를 먼저 조회하고, 이미 정지했다면 stop을 다시 보내지 않는다.
기본 TCP 이름과 플랜지 일치까지 확인되면 모드/TCP 재설정도 생략한다.
정지 명령이 실패해도 별도 조회에서 IDLE이 확인돼야만 복원을 이어간다.
계속 BUSY이거나 실제 TCP 오프셋이 남아 있으면 실패로 처리한다. 그리기 자체의 실패는 숨기지 않는다.

윗면 재조정: 513.89 → 512.89mm로 1mm 낮췄다(최초 티칭 대비 총 +2.5mm). 현재 접근점은 522.89mm다. 옆면 설정은 유지한다.

윗면 미세 조정: 512.89 → 512.69mm로 0.2mm 낮췄다(최초 티칭 대비 총 +2.3mm). 현재 접근점은 522.69mm다. 옆면 설정은 유지한다.

윗면 미세 조정: 512.69 → 512.79mm로 0.1mm 올렸다(최초 티칭 대비 총 +2.4mm). 현재 접근점은 522.79mm다. 옆면 설정은 유지한다.

윗면 높이 조정: 512.79 → 513.29mm로 0.5mm 올렸다(최초 티칭 대비 총 +2.9mm). 현재 접근점은 523.29mm다. 옆면 설정은 유지한다.

## 옆면 하단 10mm 제한

스테이지와 굵은 펜의 충돌을 피하도록 바닥에서 10mm 아래 영역에는 그릴 수 없다.
프론트 옆면 편집 띠의 하단을 회색으로 표시하고 입력을 막는다. 케이크 79mm 전체 비율은 유지한다.
작업 관리 노드는 해당 영역을 포함한 주문을 케이크 운반 전에 거부하고, DP도 원본 좌표를 다시 검사한다.
금지 영역을 포함한 획을 잘라 이어 붙이거나 위쪽으로 압축하지 않는다. 사용자가 수정 후 다시 제출해야 한다.
현재 옆면 펜촉 TCP 기준 상면 Z=222mm, 케이크 높이79mm이므로 입력 가능한 최저 표면 Z는153mm다.


## 이동 속도와 경유점 정리

- 출고 케이크 재진입의 `pickup_cake_station_ps1`은 생략하고 ps2부터 실행한다.
- TOP 반납 위치가 실측으로 확인되면 SIDE 파지의 중복 관절 상공 접근을 생략한다. 위치가 달라졌으면 원래 접근을 유지한다.
- 옆면 획 사이는 현재 높이에서 최대 반지름 밖으로 빠진 뒤 각도·높이를 함께 보간한다. 상면 위로 올라가지 않는다.
- 주문에서 다음 면이 남았는지는 `DrawOnCake.has_more_surfaces`로 전달한다. TOP→SIDE 중간 반납·재파지는 기존 속도이고, 마지막 그림 뒤 반납은 가속한다.

| 구간 | 기존 | 변경 |
|---|---|---|
| 케이크를 들지 않은 일반 관절 이동 | 30도/s | 45도/s |
| 케이크를 들지 않은 일반 직선 이동 | 50mm/s | 75mm/s |
| 따개 거치대 접근 / 하강·인출 | 80 / 30mm/s | 120 / 45mm/s |
| 케이크 첫 들어올림(상대 Z+80mm) | 50mm/s | 25mm/s |
| 작업대 안착·회수 상승·출고 하강의 지정 관절 동작 | 30도/s | 15도/s |
| 그리기·파지 후 케이크 접근·케이크 운반의 나머지 구간 | 기존값 | 유지 |

가속도도 구간별로 조정한다. 일반/케이크 상하 속도는 `workspace_config.yaml`의 `free_*`, `cake_lift_*`, `cake_seat_*`에서 조정한다.
SIDE 최종 반납은 기존 30→45도/s, 60→90mm/s로 변경했다. J6 되감기 동작은 유지한다.
Action 필드가 추가됐으므로 `cake_decorator_interfaces`와 `cake_decorator`를 함께 빌드하고 업무 실행기를 재시작해야 한다.
새 연결 경로와 속도는 실물 검증이 필요하다. 좌표·유격·하단 10mm 제한과 그리퍼 대기는 변경하지 않는다.

최신 main 반영 후 윗면 높이: 513.29 → 513.79mm로 0.5mm 올렸다. 옆면 설정은 유지한다.

윗면 높이: 513.79 → 513.59mm로 0.2mm 낮췄다.

윗면 Z는 513.59 → 513.46mm로 0.13mm 낮췄다. 통합 실행 그리기 속도는 TOP/SIDE 30→40mm/s, 공중 이동은 100→120mm/s다(100% 기준).


## 펜 이동 속도·제자리 재파지 보완

펜 인출100mm/s, 첫 획 상공 이동120mm/s, 거치대 반납 하강80mm/s로 조정했다.
YAML의 pen_lift_speed_mm_s, pen_travel_speed_mm_s, pen_rack_speed_mm_s, pen_motion_acc_mm_s2에서 조절한다.
옆면 공중 자세 전환 movejx는 관절10→30도/s, 가속도20→60도/s²다.
TOP 후 SIDE가 남으면 펜을 놓고 그리퍼를 연 위치에서 바로 45도 재파지한다.
반납 후 상공 후퇴와 재하강을 없앴다. 반납 위치가 확인되지 않으면 자동 상공 우회 대신 실패로 중단한다.
새 실행기 시작 로그에 인출/공중/반납 속도와 TOP→SIDE 제자리 재파지가 표시된다.

중심 미세 조정: X=396.7743225097656mm, Y=-50.75932998657227mm. 지름 유격은8.0mm로 조정했다.

## 윗면 십자가 중심 시험

현재 윗면 높이는513.51mm(기존513.46mm에서 +0.05mm)다.
`python3 scripts/draw_top_center_cross.py --preview`는 가로·세로 각50mm 좌표만 출력한다.
실물 실행기를 새로 시작한 뒤 `python3 scripts/draw_top_center_cross.py`로 TOP 주문 하나를 제출한다.
기존 전체 공정대로 케이크 운반·펜 파지·그리기·반납·회수가 진행된다.
각 선은 중심 양쪽25mm이며, 중심 오차는 선 끝과 케이크 가장자리 사이 여백을 비교한다.

십자가 접촉 높이 미세 조정: 윗면 Z=513.51 → 513.48mm로 0.03mm 낮췄다.

## 윗면 중심 보정과 외곽 제한

십자가 여백(-X26.5,+X34,+Y27.5,-Y32mm)의 차이를 반으로 나눠 윗면만 +X3.75,-Y2.25mm 보정했다.
`real_robot.json`의 `top_cake_center_xy_mm`=[400.5243225097656,-53.00932998657227]mm다.
기존 옆면 `side_cake_center_xy_mm`는 유지한다. TOP 키가 없으면 옛 설정 호환을 위해 SIDE 키를 사용한다.
윗면 가장자리5mm는 회색 입력 금지 영역이며 ROS도 같은 여유를 검사한다. 그림 축척은 바꾸지 않는다.
허용 최대 반경은56.75−5=51.75mm다. 이전 외곽 데이터는 실행 거부될 수 있으므로 새로 그려야 한다.
